# Карта навигации приложения

## Легенда

| Обозначение | Значение |
|---|---|
| **→** | Переход по действию пользователя |
| **⇢** | Переход из системного уведомления (push) |
| **⬇** | Модальное открытие / bottom sheet |
| **←** | Кнопка «Назад» |
| **⟷** | Нижняя навигация (tab bar) |

---

## Схема навигации

```mermaid
graph TD
    Launch(Launch / Splash) --> Login[S-01: Вход]
    Launch --> Reg[S-02: Регистрация]

    Login -->|Успех| Schedule[S-03: Расписание]
    Reg -->|Успех| Schedule
    Login -->|Ссылка «Зарегистрироваться»| Reg
    Reg -->|Ссылка «Войти»| Login

    Schedule -->|Тап по слоту| Slot[S-04: Детали слота]
    Schedule -->|Тап по имени мастера| Master[S-08: Профиль мастера]
    Schedule -->|Тап по программе| Program[S-09: Программа]

    Slot -->|«Записаться» → успех| MyBookings[S-05: Мои записи]
    Slot -->|Тап по мастеру| Master
    Slot -->|Тап по программе| Program

    Schedule ⟷|Tab Bar| MyBookings

    MyBookings -->|Тап по брони| Booking[S-06: Детали брони]
    MyBookings -->|Кнопка «Оценить»| Rate[S-07: Оценка мастера]

    Booking -->|«Отменить» → успех| MyBookings
    Booking -->|Тап по мастеру| Master

    Rate -->|«Отправить» → успех| MyBookings

    PushReminder(Push: напоминание) ⇢ Slot
    PushCancel(Push: отмена мастерской) ⇢ Booking

    Master -->|Тап по программе| Program
    Program -->|Тап по мастеру| Master

    style Launch fill:#e0e0e0,stroke:#999
    style PushReminder fill:#f9e6b3,stroke:#d4a017
    style PushCancel fill:#f9e6b3,stroke:#d4a017
```

## Группировка по стекам навигации

```
Стек аутентификации
    S-01 (Login) ⇄ S-02 (Registration)

Стек клиента (Tab Bar)
    S-03 (Schedule) ⟷ S-05 (MyBookings)

Модальные / push-экраны (открываются поверх стека)
    S-04 (Slot Details)
    S-06 (Booking Details)
    S-07 (Rate Master)
    S-08 (Master Profile)
    S-09 (Program Details)
```
