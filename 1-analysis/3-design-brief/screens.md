# Реестр экранов приложения

## Сокращения
- **ВК** — высокий критический
- **В** — высокий
- **С** — средний
- **Н** — низкий

---

### S-01: Экран входа

| Параметр | Значение |
|---|---|
| Связанные требования | ФТ-02, UC-02, US-02 |
| Приоритет | ВК |
| Назначение | Аутентификация зарегистрированного клиента по логину и паролю |

**Состав экрана:**
- Поле ввода «Логин»
- Поле ввода «Пароль» (с переключателем видимости)
- Кнопка «Войти»
- Ссылка «Зарегистрироваться» (переход на S-02)

**Состояния:**
- Успех → переход на главный экран (S-03)
- Ошибка валидации (пустые поля)
- Ошибка аутентификации (неверные логин/пароль) с текстом ошибки
- Загрузка (индикатор на кнопке)

---

### S-02: Экран регистрации

| Параметр | Значение |
|---|---|
| Связанные требования | ФТ-01, UC-01, US-01 |
| Приоритет | ВК |
| Назначение | Создание учётной записи клиента по логину и паролю |

**Состав экрана:**
- Поле ввода «Логин»
- Поле ввода «Пароль» (с требованиями к длине/сложности)
- Поле ввода «Подтверждение пароля»
- Кнопка «Зарегистрироваться»
- Ссылка «Уже есть аккаунт? Войти» (переход на S-01)

**Состояния:**
- Успех → автоматический вход, переход на S-03
- Ошибка валидации (пароли не совпадают, слишком короткий пароль, занятый логин)
- Загрузка

---

### S-03: Главный экран — Расписание

| Параметр | Значение |
|---|---|
| Связанные требования | ФТ-03, UC-03, US-03 |
| Приоритет | ВК |
| Назначение | Просмотр доступных слотов на 7 дней вперёд для выбора занятия |

**Состав экрана:**
- Заголовок «Расписание»
- Горизонтальный календарь / список дат на 7 дней с подсветкой сегодня
- Список слотов на выбранную дату:
  - Название программы
  - ФИО мастера
  - Время начала и окончания
  - Кол-во свободных мест / всего мест
  - Индикатор доступности проката инструментов
  - Кнопка/карточка «Записаться»
- Нижняя навигация (S-03, S-05)
- Pull-to-refresh

**Состояния:**
- Загрузка (скелетон списка)
- Пусто (нет слотов на выбранную дату) — плашка с пояснением
- Ошибка загрузки — кнопка «Повторить»
- Слот полностью заполнен — серая карточка «Нет мест»

**Навигация:**
- Тап по слоту → S-04
- Тап по имени мастера → S-08
- Тап по программе → S-09

### S-04: Экран деталей слота / Запись

| Параметр | Значение |
|---|---|
| Связанные требования | ФТ-04, UC-04, US-04 |
| Приоритет | ВК |
| Назначение | Просмотр подробной информации о занятии и запись на него |

**Состав экрана:**
- Название программы (крупно)
- Фото и имя мастера (тап → S-08)
- Дата, время начала и окончания
- Описание программы / что входит
- Вместимость: «N свободных из M мест»
- Переключатель «Арендовать инструменты» (да/нет)
- Кнопка «Записаться» (крупная)

**Состояния:**
- Загрузка деталей
- Слот недоступен (прошёл, нет мест) — кнопка неактивна с пояснением
- Успех записи → сообщение об успехе, переход в S-05
- Ошибка записи (конфликт, сбой) — текст ошибки
- Клиент уже записан на этот слот — индикатор «Вы записаны», кнопка неактивна

---

### S-05: Экран «Мои записи»

| Параметр | Значение |
|---|---|
| Связанные требования | ФТ-05, UC-05, US-05 |
| Приоритет | В |
| Назначение | Просмотр списка всех броней клиента с их статусами |

**Состав экрана:**
- Заголовок «Мои записи»
- Табы / фильтры: «Активные», «Отменённые», «Прошедшие»
- Список броней:
  - Название программы
  - Дата и время
  - Имя мастера
  - Статус (активна, отменена клиентом, отменена мастерской)
  - Если прошедшая и не оценена → кнопка «Оценить мастера»
- Нижняя навигация (S-03, S-05)

**Состояния:**
- Загрузка
- Пусто (нет записей) — плашка с предложением перейти к расписанию
- Ошибка загрузки

**Навигация:**
- Тап по брони → S-06
- Тап «Оценить» → S-07

### S-06: Экран деталей брони / Отмена

| Параметр | Значение |
|---|---|
| Связанные требования | ФТ-06, UC-06, US-06, НФТ-05, НФТ-06 |
| Приоритет | В |
| Назначение | Просмотр подробной информации о брони и её отмена |

**Состав экрана:**
- Название программы
- Дата и время
- Имя мастера
- Статус брони
- Отметка о прокате инструментов (если выбран)
- Блок с действием:
  - Если до начала ≥ 4 ч → кнопка «Отменить запись» + подтверждение
  - Если до начала < 4 ч → текст «Отмена менее чем за 4 часа — обратитесь в поддержку»
  - Если статус «Отменена мастерской» → причина отмены, кнопка недоступна
  - Если статус «Отменена клиентом» или прошедшая — действия нет

**Состояния:**
- Загрузка
- Подтверждение отмены (диалог: «Вы уверены?»)
- Успех отмены → обновление статуса
- Ошибка отмены

---

### S-07: Экран оценки мастера

| Параметр | Значение |
|---|---|
| Связанные требования | ФТ-07, UC-07, US-07, НФТ-04 |
| Приоритет | С |
| Назначение | Оценка мастера по 5-звёздочной шкале после посещения занятия |

**Состав экрана:**
- Фото и имя мастера
- Название программы и дата посещения
- 5 звёзд (тапом выбирается оценка)
- Кнопка «Отправить оценку»

**Состояния:**
- Окно оценки закрыто (до 1 ч после окончания или после 48 ч) — скрытый экран, недоступен
- Оценка не выбрана — кнопка неактивна
- Успех отправки — сообщение «Спасибо за оценку!», возврат на S-05
- Ошибка отправки

### S-08: Экран профиля мастера

| Параметр | Значение |
|---|---|
| Связанные требования | ФТ-09 |
| Приоритет | С |
| Назначение | Просмотр информации о мастере |

**Состав экрана:**
- Крупное фото мастера
- Имя и фамилия
- Уровень (новичок / опытный)
- Рейтинг (число и визуализация звездами)
- Список проводимых программ (тап → S-09)

**Состояния:**
- Загрузка данных мастера
- Ошибка загрузки

---

### S-09: Экран программы мастер-класса

| Параметр | Значение |
|---|---|
| Связанные требования | ФТ-10 |
| Приоритет | С |
| Назначение | Просмотр описания программы и её ограничений по вместимости |

**Состав экрана:**
- Название программы
- Описание / формат занятия
- Максимальная вместимость:
  - Новичковые группы: ≤ 6 чел.
  - Гончарный круг: ≤ 10 чел.
- Список мастеров, проводящих эту программу (тап → S-08)

**Состояния:**
- Загрузка
- Ошибка загрузки

## Системные уведомления (не экран)

| Параметр | Значение |
|---|---|
| Связанные требования | ФТ-08, UC-08, US-08, US-09 |
| Приоритет | С |
| Назначение | Push-уведомления для информирования клиента |

**Сценарии:**
1. **Напоминание** — за N времени до начала занятия: «Напоминаем: [программа] с [мастер] в [время]»
2. **Отмена мастерской** — при смене статуса брони на «Отменена мастерской»: «Занятие [программа] отменено. Причина: [текст]»
