## Обзор

Экран аутентификации зарегистрированного клиента. Содержит форму входа с полями логина и пароля. При успешной аутентификации пользователь переходит на главный экран приложения.

### User Story

> Как клиент, я хочу войти в приложение, чтобы управлять бронями.

### Бизнес-ценность

- Обеспечивает доступ к персонализированному функционалу приложения
- Защищает данные пользователя от несанкционированного доступа
- Сокращает путь пользователя до целевого экрана при наличии сессии

## Используемые запросы

### POST /auth/login

**Тип:** REST  
**Метод:** POST  
**Спецификация:** [openapi.yaml](../../api/openapi.yaml) → `authLogin`

**Триггер:** Тап на кнопку "Войти" (после успешной валидации)

**Параметры:**

| Параметр | Тип | Обязательность | Источник | Описание |
|----------|-----|----------------|----------|----------|
| `login` | string | Да | Поле "Логин" | Email или номер телефона пользователя |
| `password` | string | Да | Поле "Пароль" | Пароль пользователя (минимум 6 символов) |

**Обработка ответа:**

| Результат | Условие | UI-реакция |
|-----------|---------|------------|
| Загрузка | — | Лоадер на кнопке, блокировка полей ввода |
| Успех | 200 | Сохранить токен в SecureStorage, переход на [SCR-003](./SCR-003_Главная.md) |
| HTTP 4xx | 400 | Снек с текстом ошибки из `message` |
| HTTP 4xx | 401 | Снек "Неверный логин или пароль" |
| HTTP 5xx | — | Снек "Произошла ошибка. Попробуйте позже" |
| Сеть | Нет соединения | Снек "Нет соединения. Проверьте подключение" |

## Элементы экрана

### 1. Форма входа

| Элемент | Описание | Источник данных | Валидация | Действие |
|---------|----------|-----------------|-----------|----------|
| Поле "Логин*" | Email или номер телефона | Ввод пользователя | Непустое значение. Ошибка: "Введите логин" | — |
| Поле "Пароль*" | Пароль пользователя. Скрытый ввод с иконкой глаза для переключения видимости | Ввод пользователя | Не менее 6 символов. Ошибка: "Пароль должен содержать не менее 6 символов" | Тап на иконку глаза → переключение видимости пароля |
| Кнопка "Войти" | Primary button отправки формы | — | — | Валидация → [POST /auth/login](#post-authlogin) |

**Момент валидации:** При отправке формы (тап на кнопку "Войти")

**Логика:**
- Кнопка "Войти": [LOGIC-001 Аутентификация](../09_Логики/LOGIC-001_Аутентификация.md) — при тапе выполняется валидация полей, при успехе — POST /auth/login, при 200 — сохранение токена и переход на [SCR-003](./SCR-003_Главная.md)

**Условия доступности:**
- Кнопка "Войти" активна всегда (валидация выполняется при тапе)

## Критерии приёмки

### Позитивные сценарии

| ID | Критерий | Приоритет |
|----|----------|-----------|
| AC-001 | **Дано** корректные логин и пароль, **Когда** пользователь тапает "Войти", **Тогда** выполняется POST /auth/login, при 200 токен сохраняется, выполняется переход на SCR-003 | P0 |

### Негативные сценарии

| ID | Критерий | Приоритет |
|----|----------|-----------|
| AC-N01 | **Дано** неверный пароль, **Когда** пользователь тапает "Войти", **Тогда** POST /auth/login возвращает 401, отображается снек "Неверный логин или пароль" | P0 |
| AC-N02 | **Дано** пустое поле логина, **Когда** пользователь тапает "Войти", **Тогда** отображается ошибка валидации "Введите логин" | P1 |
| AC-N03 | **Дано** пароль короче 6 символов, **Когда** пользователь тапает "Войти", **Тогда** отображается ошибка валидации "Пароль должен содержать не менее 6 символов" | P1 |
| AC-N04 | **Дано** ошибка сети, **Когда** отправка POST /auth/login, **Тогда** отображается снек "Нет соединения. Проверьте подключение" | P1 |

### Edge Cases

| ID | Критерий | Приоритет |
|----|----------|-----------|
| AC-E01 | **Дано** пользователь на экране входа, **Когда** сессия уже активна, **Тогда** экран не открывается — выполняется редирект на SCR-003 | P0 |
