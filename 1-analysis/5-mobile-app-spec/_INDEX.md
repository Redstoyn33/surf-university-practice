## Карта навигации

```
Splash ──→ S-01/S-02 (по наличию сессии)
S-01 Вход ⇄ S-02 Регистрация
S-01/S-02 → S-03 Расписание (успех)

S-03 Расписание ⟷ S-05 Мои записи (Tab Bar)
S-03 → S-04 Детали слота (тап по слоту)
S-03 → S-08 Профиль мастера (тап по мастеру)
S-03 → S-09 Программа (тап по программе)

S-04 → S-05 Мои записи (успех брони)
S-04 → S-08 (тап по мастеру)
S-04 → S-09 (тап по программе)

S-05 → S-06 Детали брони (тап по брони)
S-05 → S-07 Оценка мастера (тап «Оценить»)

S-06 → S-05 (успех отмены)
S-06 → S-08 (тап по мастеру)

S-07 → S-05 (успех оценки)

S-08 → S-09 (тап по программе)
S-09 → S-08 (тап по мастеру)
```
