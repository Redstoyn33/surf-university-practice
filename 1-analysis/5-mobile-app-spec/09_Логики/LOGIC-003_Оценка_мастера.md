## Обзор

После завершения занятия клиент может оценить мастера по шкале от 1 до 5. Оценка доступна только в окне от 1 часа до 48 часов после окончания слота. До истечения 1 часа или после 48 часов сервер возвращает ошибку 422.

### User Story

> Как клиент, я хочу оценить мастера после занятия, чтобы поделиться впечатлениями и помочь другим клиентам с выбором.

### Бизнес-ценность

- Формирует рейтинг мастеров, помогая клиентам выбирать
- Мотивирует мастеров поддерживать качество услуг
- Собирает обратную связь для улучшения сервиса

## API запросы

### POST /ratings

**Триггер:** Тап на кнопку "Отправить"

**Headers:**

| Поле | Описание |
|------|----------|
| `authorization` | Bearer токен пользователя |
| `Content-Type` | `application/json` |

**Body:**

| Параметр | Тип | Описание | Значение/Источник |
|----------|-----|----------|-------------------|
| `masterId` | string | ID мастера | Из данных брони |
| `slotId` | string | ID слота | Из данных брони |
| `score` | int | Оценка мастера (1–5) | Из выбранного значения на экране оценки |

**Обработка ответа:**

| Результат | Действие |
|-----------|----------|
| Загрузка | Лоадер на кнопке "Отправить" |
| Успех (201) | Показать снек "Спасибо за оценку!", вернуться на экран "Мои записи" |
| Ошибка 400 | Снек с текстом ошибки из ответа сервера |
| Ошибка 401 | Снек "Неавторизованный доступ. Выполните вход" |
| Ошибка 422 | Снек "Оценка доступна в окне от 1 до 48 часов после окончания занятия" |
| Ошибка 5xx | Снек "Произошла ошибка. Попробуйте позже" |
| Ошибка сети | Снек "Нет соединения. Проверьте подключение к интернету" |

## Критерии приёмки

| ID | Критерий |
|----|----------|
| AC-001 | **Дано** у клиента есть завершённый слот, **Когда** с момента окончания прошло от 1 до 48 часов и клиент отправляет оценку 1–5, **Тогда** оценка принимается, показывается снек "Спасибо за оценку!" |
| AC-002 | **Дано** у клиента есть завершённый слот, **Когда** с момента окончания прошло менее 1 часа, **Тогда** кнопка "Оценить" неактивна или при тапе показывается снек "Оценка будет доступна через {{x}} минут" |
| AC-003 | **Дано** у клиента есть завершённый слот, **Когда** с момента окончания прошло более 48 часов, **Тогда** при попытке оценить показывается снек "Время оценки истекло" |
| AC-004 | **Дано** клиент на экране оценки, **Когда** он вводит оценку вне диапазона 1–5, **Тогда** сервер возвращает 400 и показывается снек с ошибкой |
