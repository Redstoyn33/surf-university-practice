## Обзор

Клиент может отменить активную бронь. Если до начала занятия остаётся 4 часа и более, отмена выполняется бесплатно. Если до начала менее 4 часов, сервер возвращает ошибку 422 — отмена в этот период недоступна.

### User Story

> Как клиент, я хочу отменить бронь, чтобы освободить место и не занимать слот, если планы изменились.

### Бизнес-ценность

- Освобождает слоты для других клиентов
- Предотвращает отмены в последний момент, давая мастерской возможность планировать загрузку

## API запросы

### PATCH /bookings/{bookingId}/cancel

**Триггер:** Подтверждение отмены в диалоге

**Headers:**

| Поле | Описание |
|------|----------|
| `authorization` | Bearer токен пользователя |

**Параметры:**

| Параметр | Тип | Описание | Значение/Источник |
|----------|-----|----------|-------------------|
| `bookingId` | string | ID брони для отмены | Из данных текущей брони |

**Body:** отсутствует

**Обработка ответа:**

| Результат | Действие |
|-----------|----------|
| Загрузка | Лоадер на кнопке "Отменить" |
| Успех (200) | Обновить статус брони на "отменена клиентом", вернуться к списку броней |
| Ошибка 401 | Снек "Неавторизованный доступ. Выполните вход" |
| Ошибка 404 | Снек "Бронь не найдена" |
| Ошибка 422 | Снек "Отмена брони доступна не менее чем за 4 часа до начала занятия" |
| Ошибка 5xx | Снек "Произошла ошибка. Попробуйте позже" |
| Ошибка сети | Снек "Нет соединения. Проверьте подключение к интернету" |

## Критерии приёмки

| ID | Критерий |
|----|----------|
| AC-001 | **Дано** у клиента есть активная бронь, **Когда** он нажимает "Отменить бронь" и подтверждает, и до начала слота ≥ 4 часов, **Тогда** броня отменяется, статус меняется на "отменена клиентом" |
| AC-002 | **Дано** у клиента есть активная бронь, **Когда** он нажимает "Отменить бронь" и подтверждает, и до начала слота < 4 часов, **Тогда** отображается снек "Отмена брони доступна не менее чем за 4 часа до начала занятия" |
| AC-003 | **Дано** клиент пытается отменить несуществующую бронь, **Когда** сервер возвращает 404, **Тогда** отображается снек "Бронь не найдена" |
| AC-004 | **Дано** клиент нажимает "Отменить", **Когда** открыт диалог подтверждения и пользователь нажимает "Нет", **Тогда** диалог закрывается, отмена не выполняется |
