## Обзор

Экран создания учётной записи нового клиента. Содержит форму регистрации с полями логина, пароля и подтверждения пароля. При успешной регистрации выполняется автоматический вход с переходом на главный экран.

### User Story

> Как новый клиент, я хочу зарегистрироваться, чтобы пользоваться приложением.

### Бизнес-ценность

- Расширяет клиентскую базу мастерской
- Обеспечивает бесшовный вход после регистрации (авто-вход)
- Минимизирует количество шагов до целевого экрана

## Используемые запросы

### POST /auth/register

**Тип:** REST  
**Метод:** POST  
**Спецификация:** [openapi.yaml](../../api/openapi.yaml) → `authRegister`

**Триггер:** Тап на кнопку "Зарегистрироваться" (после успешной валидации)

**Параметры:**

| Параметр | Тип | Обязательность | Источник | Описание |
|----------|-----|----------------|----------|----------|
| `login` | string | Да | Поле "Логин" | Email или номер телефона пользователя |
| `password` | string | Да | Поле "Пароль" | Пароль пользователя (минимум 6 символов) |

**Обработка ответа:**

| Результат | Условие | UI-реакция |
|-----------|---------|------------|
| Загрузка | — | Лоадер на кнопке, блокировка полей ввода |
| Успех | 201 | Сохранить токен в SecureStorage (авто-вход), переход на [SCR-003](./SCR-003_Главная.md) |
| HTTP 4xx | 400 | Снек с текстом ошибки из `message` |
| HTTP 4xx | 409 | Снек "Логин уже занят" |
| HTTP 5xx | — | Снек "Произошла ошибка. Попробуйте позже" |
| Сеть | Нет соединения | Снек "Нет соединения. Проверьте подключение" |

## Элементы экрана

### 1. Форма регистрации

| Элемент | Описание | Источник данных | Валидация | Действие |
|---------|----------|-----------------|-----------|----------|
| Поле "Логин*" | Email или номер телефона | Ввод пользователя | Непустое значение, формат email или телефона. Ошибка: "Введите корректный email или номер телефона" | — |
| Поле "Пароль*" | Пароль пользователя. Скрытый ввод с иконкой глаза для переключения видимости | Ввод пользователя | Не менее 6 символов. Ошибка: "Пароль должен содержать не менее 6 символов" | Тап на иконку глаза → переключение видимости пароля |
| Поле "Подтверждение пароля*" | Повторный ввод пароля для подтверждения | Ввод пользователя | Значение должно совпадать с полем "Пароль". Ошибка: "Пароли не совпадают" | — |
| Кнопка "Зарегистрироваться" | Primary button отправки формы | — | — | Валидация → [POST /auth/register](#post-authregister) |

**Момент валидации:** При отправке формы (тап на кнопку "Зарегистрироваться")

**Логика:**
- Кнопка "Зарегистрироваться": [LOGIC-001 Аутентификация](../09_Логики/LOGIC-001_Аутентификация.md) — при тапе выполняется валидация всех полей, при успехе — POST /auth/register, при 201 — сохранение токена (авто-вход) и переход на [SCR-003](./SCR-003_Главная.md)

**Условия доступности:**
- Кнопка "Зарегистрироваться" активна всегда (валидация выполняется при тапе)

## Критерии приёмки

### Позитивные сценарии

| ID | Критерий | Приоритет |
|----|----------|-----------|
| AC-001 | **Дано** корректные логин, пароль и подтверждение, **Когда** пользователь тапает "Зарегистрироваться", **Тогда** выполняется POST /auth/register, при 201 токен сохраняется (авто-вход), выполняется переход на SCR-003 | P0 |

### Негативные сценарии

| ID | Критерий | Приоритет |
|----|----------|-----------|
| AC-N01 | **Дано** пароль и подтверждение не совпадают, **Когда** пользователь тапает "Зарегистрироваться", **Тогда** отображается ошибка валидации "Пароли не совпадают", запрос не отправляется | P0 |
| AC-N02 | **Дано** пароль короче 6 символов, **Когда** пользователь тапает "Зарегистрироваться", **Тогда** отображается ошибка валидации "Пароль должен содержать не менее 6 символов" | P1 |
| AC-N03 | **Дано** логин уже занят, **Когда** пользователь тапает "Зарегистрироваться", **Тогда** POST /auth/register возвращает 409, отображается снек "Логин уже занят" | P0 |
| AC-N04 | **Дано** невалидный формат логина, **Когда** пользователь тапает "Зарегистрироваться", **Тогда** отображается ошибка валидации "Введите корректный email или номер телефона" | P1 |
| AC-N05 | **Дано** ошибка сети, **Когда** отправка POST /auth/register, **Тогда** отображается снек "Нет соединения. Проверьте подключение" | P1 |

### Edge Cases

| ID | Критерий | Приоритет |
|----|----------|-----------|
| AC-E01 | **Дано** пользователь на экране регистрации, **Когда** сессия уже активна, **Тогда** экран не открывается — выполняется редирект на SCR-003 | P0 |
