# Домен: онлайн-запись в гончарную мастерскую «Глина»

## Контекст
Небольшая гончарная мастерская в центре города. Третий год проводят мастер-классы.
Текущий процесс записи — Instagram Direct + бумажный ежедневник, что приводит к
ошибкам (двойные брони, потерянные заявки). Требуется клиентское мобильное приложение
для самостоятельной записи.

## Границы текущей поставки
- **Только клиентское мобильное приложение** + API к нему.
- Существующий бэкенд — black-box: приложение потребляет слоты, программы, мастеров;
  не создаёт и не редактирует.
- Интерфейсы мастера и администратора уже реализованы в инфраструктуре.
- Оплата, программа лояльности — отложены.

## Ключевые сущности

| Сущность | Описание |
|---|---|
| **Клиент** | Пользователь приложения. Регистрируется (логин + пароль), записывается на слоты, отменяет бронь, ставит оценку мастеру. |
| **Мастер** | Сотрудник, проводящий занятие. Имя, фото, рейтинг, уровень (новичок/опытный). Данные приходят из бэкенда. |
| **Программа** | Типовой мастер-класс (лепка для новичков, гончарный круг и т.д.). Имеет ограничение по вместимости. |
| **Слот расписания** | Конкретное занятие: дата/время, программа, мастер, свободные места, доступность проката. Горизонт показа — 7 дней по умолчанию. |
| **Бронь** | Запись клиента на слот. Статусы: активна, отменена клиентом, отменена мастерской. |
| **Оценка** | 5-звёздочный рейтинг мастера от клиента после занятия. |

## Основные сценарии
1. Регистрация / вход
2. Просмотр расписания (список свободных слотов на 7 дней)
3. Запись на слот (с выбором проката инструментов)
4. Просмотр и отмена своих записей
5. Оценка мастера после занятия
6. Получение push-уведомлений (напоминание, отмена мастерской)

## Бизнес-правила (зафиксированные)
- Вместимость: новичковые группы ≤ 6 чел., гончарный круг ≤ 10 чел.
- Бесплатная отмена — за 4+ часа до начала; менее 4 часов — только через поддержку.
- При отмене мастерской бронь меняет статус на «Отменено мастерской» с указанием причины;
  повторная запись на этот слот запрещена.
- Оценка мастера доступна через 1 час после окончания, окно — 48 часов.
- Клиент записывает только себя (не групповые брони).
