# Нефункциональные требования (НФТ)

| ID | Формулировка | Приоритет | Источник |
|---|---|---|---|
| НФТ-01 | Реализовать клиентское мобильное приложение (iOS/Android); веб-версия и админка не входят в поставку | Высокий | Границы поставки |
| НФТ-02 | Приложение взаимодействует с существующим бэкендом через API; бэкенд считается black-box — слоты, программы и мастера только потребляются, не создаются и не редактируются | Высокий | Границы поставки |
| НФТ-03 | Расписание показывается с горизонтом 7 дней по умолчанию | Средний | Сущность «Слот расписания» |
| НФТ-04 | Оценка мастера становится доступной через 1 час после окончания занятия и закрывается через 48 часов | Средний | Бизнес-правила |
| НФТ-05 | Бесплатная отмена брони возможна не менее чем за 4 часа до начала; менее 4 часов — только через поддержку | Высокий | Бизнес-правила |
| НФТ-06 | При отмене брони мастерской клиент видит причину отмены; повторная запись на этот слот запрещена | Средний | Бизнес-правила |
| НФТ-07 | Клиент может записать только себя; групповые брони не поддерживаются | Высокий | Бизнес-правила |
