# Тест-кейсы: Приложение «Глини»

## Формат

```
TC-NNN | Приоритет | FR / UC | Описание
        |           |         | Given / When / Then
```

## 1. Аутентификация (TC-001 – TC-016)

### TC-001 | P0 | ФТ-01, UC-01 | Регистрация — успех
- **Given** несуществующий логин «newuser@test.com» и пароль «password123»
- **When** POST /auth/register с `{"login":"newuser@test.com","password":"password123"}`
- **Then** ответ 201, тело содержит `id`, `login`, `token`, `createdAt`

### TC-002 | P0 | ФТ-01, UC-01 | Регистрация — дубликат логина
- **Given** существующий логин «existing@test.com» (уже зарегистрирован)
- **When** POST /auth/register с тем же логином
- **Then** ответ 409, `{"error":"логин уже занят"}`

### TC-003 | P1 | ФТ-01 | Регистрация — пустой логин
- **Given** логин = «»
- **When** POST /auth/register с `{"login":"","password":"pass123"}`
- **Then** ответ 400

### TC-004 | P1 | ФТ-01 | Регистрация — короткий пароль (<6 символов)
- **Given** пароль длиной 5 символов
- **When** POST /auth/register с `{"login":"user@test.com","password":"abc12"}`
- **Then** ответ 400

### TC-005 | P1 | ФТ-01 | Регистрация — невалидный JSON
- **Given** тело запроса — не JSON
- **When** POST /auth/register с телом «not json»
- **Then** ответ 400, `{"error":"некорректный JSON"}`

### TC-006 | P0 | ФТ-02, UC-02 | Вход — успех
- **Given** зарегистрированный клиент (login=«test@test.com», password=«pass123»)
- **When** POST /auth/login с верными credentials
- **Then** ответ 200, тело содержит `token` (непустой JWT) и `client` с `id` и `login`

### TC-007 | P0 | ФТ-02, UC-02 | Вход — неверный пароль
- **Given** зарегистрированный клиент
- **When** POST /auth/login с неверным паролем
- **Then** ответ 401, `{"error":"неверный логин или пароль"}`

### TC-008 | P0 | ФТ-02, UC-02 | Вход — несуществующий логин
- **Given** логин, которого нет в системе
- **When** POST /auth/login с любым паролем
- **Then** ответ 401, `{"error":"неверный логин или пароль"}`

### TC-009 | P2 | ФТ-02 | Вход — пустое тело
- **Given** тело запроса = `{}`
- **When** POST /auth/login
- **Then** ответ 400

### TC-010 | P1 | ФТ-02 | Проверка JWT — формат
- **Given** успешный вход
- **When** декодировать токен (base64url)
- **Then** payload содержит `client_id` (число), `exp` (timestamp), `iat` (timestamp)

### TC-011 | P1 | ФТ-02 | Проверка JWT — срок действия 24ч
- **Given** токен, полученный при входе
- **When** проверить `exp` - `iat`
- **Then** разница ≈ 86400 секунд (24 часа)

### TC-012 | P1 | ФТ-02 | Защищённый эндпоинт без токена → 401
- **Given** нет заголовка Authorization
- **When** GET /bookings
- **Then** ответ 401, `{"error":"требуется авторизация"}`

### TC-013 | P1 | ФТ-02 | Защищённый эндпоинт с неверным форматом токена
- **Given** Authorization: «Bearer invalidtoken»
- **When** GET /bookings
- **Then** ответ 401, `{"error":"невалидный токен"}`

### TC-014 | P2 | ФТ-02 | Защищённый эндпоинт с истекшим токеном
- **Given** JWT с `exp` в прошлом
- **When** GET /bookings
- **Then** ответ 401

### TC-015 | P2 | ФТ-02 | Защищённый эндпоинт без префикса Bearer
- **Given** Authorization: «Token abc123»
- **When** GET /bookings
- **Then** ответ 401, `{"error":"неверный формат токена"}`

### TC-016 | P1 | ФТ-01 | Регистрация — логин с неверным форматом (SQL-инъекция)
- **Given** логин = `"' OR '1'='1"`
- **When** POST /auth/register
- **Then** ответ 201 (login как обычная строка) или 400; не 500

## 3. Бронирование (TC-035 – TC-067)

### TC-035 | P0 | ФТ-04, UC-04 | Создание брони — успех (без проката)
- **Given** авторизованный клиент, слот с `availableSpots > 0`
- **When** POST /bookings с `{"slotId":1,"rentalSelected":false}` и Bearer-токеном
- **Then** ответ 201, `status = "активна"`, `rentalSelected = false`

### TC-036 | P0 | ФТ-04, UC-04 | Создание брони — успех (с прокатом)
- **Given** авторизованный клиент, слот с `rentalAvailable = true` и `availableSpots > 0`
- **When** POST /bookings с `{"slotId":1,"rentalSelected":true}`
- **Then** ответ 201, `rentalSelected = true`

### TC-037 | P0 | ФТ-04 | Создание брони — нет свободных мест
- **Given** слот с `availableSpots = 0`
- **When** POST /bookings
- **Then** ответ 409, `{"error":"нет свободных мест или двойная бронь"}`

### TC-038 | P0 | ФТ-04 | Создание брони — двойная бронь (тот же клиент, тот же слот)
- **Given** у клиента уже есть активная бронь на слот id=1
- **When** POST /bookings с тем же `slotId`
- **Then** ответ 409 (unique index `idx_active_booking`)

### TC-039 | P1 | ФТ-04 | Создание брони — несуществующий слот

### TC-041 | P1 | ФТ-04 | Создание брони — тело не JSON

- **When** POST /bookings

### TC-042 | P0 | ФТ-04, UC-04 | Проверка availableSpots после брони (атомарность)

### TC-046 | P1 | ФТ-05 | Список своих броней — фильтр по статусу

- **When** POST /bookings

### TC-063 | P1 | ФТ-06 | Отмена брони — проверка принадлежности (service)

## 6. Краевые случаи и инварианты (TC-098 – TC-106)

### TC-098 | P1 | ФТ-04 | Конкурентное бронирование — нет овербукинга
- **Given** слот с `availableSpots = 1`
- **When** 2 одновременных POST /bookings
- **Then** ровно 1 успешен (201), второй → 409

### TC-099 | P1 | ФТ-03 | Слот с availableSpots = 0 не показывается как доступный
- **Given** слот с `availableSpots = 0`
- **When** GET /slots
- **Then** слот возвращается, но `availableSpots = 0`; при POST → 409

### TC-100 | P1 | ФТ-06 | Отмена прошедшего слота
- **Given** бронь на слот в прошлом
- **When** PATCH /bookings/:id/cancel
- **Then** ответ 422 (time.Until(slotTime) < 4h)

### TC-101 | P2 | ФТ-04 | rentalSelected без rentalAvailable
- **Given** слот с `rentalAvailable = false`
- **When** POST /bookings с `rentalSelected: true`
- **Then** ответ 201, `rentalSelected = false` (или 400 — сценарий не специфицирован)

### TC-102 | P1 | ФТ-04, НФТ-07 | clientId не подменяется в запросе
- **Given** авторизованный клиент A (client_id=1)
- **When** POST /bookings с дополнительным полем (не специфицировано, но защита на бэкенде)
- **Then** `booking.clientId = 1` (берётся из токена, не из тела)

### TC-103 | P2 | ФТ-03 | Слоты не из будущего (прошедшие слоты)
- **Given** есть прошедшие слоты в БД
- **When** GET /slots
- **Then** слоты возвращаются (спека не запрещает); доступны для просмотра, но бронь → 422/409

### TC-104 | P1 | ФТ-05 | Статусы броней (проверка enum)
- **Given** разные брони с разными статусами
- **When** GET /bookings
- **Then** статусы только: «активна», «отменена клиентом», «отменена мастерской»

### TC-105 | P1 | ФТ-01 | Пароль ≥6 символов (граничные значения)
- **Given** пароль длины 5, 6, 7
- **When** POST /auth/register
- **Then** 5 → 400; 6 → 201; 7 → 201

### TC-106 | P2 | ФТ-03 | Хендлер 404 на несуществующий путь
- **Given** несуществующий endpoint
- **When** GET /nonexistent
- **Then** ответ 404 (от chi)
