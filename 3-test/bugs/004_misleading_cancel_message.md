# BUG-001: Вводящая в заблуждение ошибка при повторной отмене брони

## Симптом
При попытке отменить уже отменённую бронь сервер возвращает 422 с текстом
`"отмена невозможна — менее 4 часов до начала"`, даже если до начала слота
больше 4 часов. Сообщение вводит в заблуждение — реальная причина не в 4-часовом
ограничении, а в том, что бронь уже неактивна.

## Шаги воспроизведения
1. POST /auth/register → получить токен
2. POST /bookings → создать бронь на слот, который начнётся через ≥4ч
3. PATCH /bookings/:id/cancel → отменить (успех, статус = "отменена клиентом")
4. PATCH /bookings/:id/cancel → повторно отменить

**Ожидаемый результат:** HTTP 422 с текстом `"бронь уже отменена"` или подобным
**Фактический результат:** HTTP 422 с текстом `"отмена невозможна — менее 4 часов до начала"`

## Причина
В `internal/service/booking.go:58` проверка:
```go
if booking.Status != "активна" {
    return domain.Booking{}, fmt.Errorf("booking is not active: %w", domain.ErrValidation)
}
```
В `internal/handler/booking.go:132` обработчик ловит `ErrValidation` и выводит
сообщение про 4 часа независимо от реальной причины:
```go
if errors.Is(err, domain.ErrValidation) {
    writeError(w, http.StatusUnprocessableEntity, "отмена невозможна — менее 4 часов до начала")
}
```

## Предлагаемое исправление
Либо разделить ошибки (ErrValidation vs новая ErrNotActive), либо проверять
текст ошибки, либо проверять статус брони в handler и выбирать сообщение.
